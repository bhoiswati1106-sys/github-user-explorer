# 🔍 GitHub User Explorer

A responsive GitHub User Explorer web application built using HTML5, CSS3, and JavaScript.

## 🚀 Live Demo

https://bhoiswati1106-sys.github.io/github-user-explorer/

## 📌 About the Project

GitHub User Explorer allows users to search for GitHub profiles and explore their public information and repositories using the GitHub REST API.

The application fetches real-time GitHub data and provides search, filtering, sorting, and recent-user functionality without requiring a page reload.

## ✨ Features

- 🔎 Search GitHub users by username
- 👤 Display GitHub profile information
- 🖼️ Display user's GitHub profile image
- 📦 Display public repositories
- 🔍 Search repositories by name
- ⭐ Sort repositories by stars
- 🔤 Sort repositories alphabetically
- 🏷️ Filter repositories by programming language
- 🕘 Save and display recently searched users
- 💾 Store the last searched username using LocalStorage
- ⚠️ Handle invalid usernames and API errors
- ⏳ Display loading state while fetching data
- 📱 Responsive design for mobile, tablet, and desktop
- 🔗 Open repository links directly on GitHub

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- GitHub REST API
- Fetch API
- Async/Await
- LocalStorage
- CSS Flexbox
- CSS Media Queries
